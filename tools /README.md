
# Investigation Tools

This directory documents the tools and resources used during the phishing investigation.

Potential investigation resources include:

- VirusTotal
- URLScan.io
- Cisco Talos Intelligence
- AbuseIPDB
- MXToolbox
- WHOIS services
- CyberChef
- Python
- Manual email header analysis

All indicators used in this project are sanitized, defanged, or associated with a controlled fictional scenario. No live malicious links or attachments should be opened directly.
